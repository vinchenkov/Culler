# Security policy

## Report a vulnerability

Report a vulnerability in private through GitHub private vulnerability reporting:

1. Open the **Security** tab of this repository.
2. Select **Report a vulnerability**.
3. Describe the problem, the steps that show it, and the output of `culler version`.

The form is also at <https://github.com/vinchenkov/Culler/security/advisories/new>.
Do not report a vulnerability in a public issue, a pull request, or a discussion.
The repository owner reads each private report.

## Supported versions

Culler is in early access.
Only the latest release receives security fixes.
A fix for a confirmed vulnerability comes in a new version, and [CHANGELOG.md](CHANGELOG.md) describes it.
