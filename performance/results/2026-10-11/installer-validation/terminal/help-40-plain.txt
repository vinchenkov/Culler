usage: install-helper.py [-h]
                         --config CONFIG
                         --binary BINARY
                         --record RECORD

Install one Linux candidate in an
owned scratch helper and retain its
original binary.

options:
  -h, --help      show this help
                  message and exit
  --config CONFIG
                  Use the owned
                  scratch fixture
                  configuration.
  --binary BINARY
                  Read a Linux
                  candidate below the
                  fixture bin
                  directory.
  --record RECORD
                  Create this new JSON
                  record below the
                  fixture directory.
