How to interpret the percentages

Each paired trial divides the treatment duration by the control duration. The report combines those ratios with a geometric mean.

The confidence interval comes from repeated samples of whole blocks. It describes the paired ratio, not uncertainty around the median.

The median bars and percentile curves summarize individual command durations. They answer a different question from the paired ratio.

Each variant has 1,000 measured reads and ten separate initial reads. The initial reads prepare caches and remain outside the duration summaries.

What the policy experiment proves

A native launcher selected Background or Standard for each persistent Bun worker. The experiment left the deployed launchd units unchanged.

A separate native child probe recorded thread priorities of four and 31. Its task priority was 31 in both cases.

The measured effect belongs to process type across the complete command path. It does not isolate thread priority or one Docker operation.

The product policy also affects the resident. These experiments measure dashboard reads only, and do not prove every launchd resource policy.

What the concurrent experiment proves

This archived variant remains outside the product changes.

Each variant receives a finite batch of concurrent reads. The treatment admits eight Mac commands and queues other reads.

The measurement includes each read's queue time. It establishes per-read duration under this workload, not sustained browser throughput.

The worker computes each result's digest after its timer stops. That work can delay other concurrent reads on the shared Bun event loop.

The Mac limit does not establish a strict maximum of eight Linux processes. Clock differences and delays before Linux wrapper entry remain limits.

Historical validation and cleanup

These checks validate the original experimental source. They do not validate the later product changes.

  • The dashboard check passed 784 tests. The shared component check passed 93 tests with authorized host access.
  • The benchmark checks passed six Bun tests and 18 Python tests. The full mc check passed.
  • The restricted shared check failed four tests because the sandbox refused required socket or process inspection operations.
  • The first full mc check returned a failure with truncated output. Its cause remains unknown; the repeat passed with retained output.
  • Cleanup removed the exact scratch helper and volume. A separate check confirmed both resources were absent.
