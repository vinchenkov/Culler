# Productionize Culler

This is open-source software meant to demonstrate the ability of I (Vinny), the creator, to potential employers. These employers are at the frontier of AI and agentic engineering, such as Anthropic and OpenAI. They expect exceptional:
- OSS best-practices
- Clean CI/CD and release support practices
- Safe upgrades
- Security Boundaries
- Clear depiction of architecture and the system model
- Communication of design decisions, tradeoffs, usefulness of the software
- Robust control/dispatch
- Garner respect from the OSS community potential recruiters
- Production-ish software:
-- Universal great software design (decoupling, code re-use, separations of concerns, single responsibility, deep modules, interface simplification, etc.)
-- Dead code path removal
-- Useless comment removal

Improve on the above goals. They are stated in no particular order.
