Common to all four sets

The same rules, on every page.

The theme changes the colors and shape. These conventions stay the same across all dialogs and pages.

01 / Dialog structure

  • Every dialog uses the same header colors.
  • The header contains the title, context, and close button.
  • The footer contains the actions.
  • Dialog width follows its content.

02 / Surfaces

  • Every dialog uses the same body background.
  • Page panels use the dialog header colors.
  • Additional content uses one subtle surface.
  • Every dialog uses the same backdrop.

03 / Controls

  • The primary action appears on the right.
  • Secondary actions use an outlined button.
  • Dangerous actions use red and explicit text.
  • Controls share their shape and focus outline.

04 / Content

  • Titles use sentence case.
  • Labels appear above form fields.
  • Status labels use text and color.
  • Green means success. Amber means attention.
