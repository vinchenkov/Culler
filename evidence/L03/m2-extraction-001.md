# L03 M-2 无假设抽取 #1（用"对公开语料求差集"取代"凭记忆列族"）

性质=**方法验证 + 决策支持**。触发理由=同日勘误（`g4-census-erratum-001.md`）证明 v1 普查凭记忆列族，漏掉频率最高的宿主主机名族。本件检验设计件 §3b 的 M-2 路线是否真能发现"记忆之外的东西"，并给出其成本。
**本件不含任何命中值。** 候选值表留在仓外：`~/.culler-local/l03-m2/`（0700 目录/0600 文件，实测），其中 `env-host-specific.tsv` sha256 前缀 `0e474d1f7e971a56…`。这正是 V-1 custody 的一次**可运行示范**：形状与账目入仓、真值留仓外。

## 1. 方法（三步，全部机器判定，无人工列族）
1. **公开语料**：`git archive main | tar -x`（上游 2144 文件/45 MB）→ 抽全部 `[A-Za-z][A-Za-z0-9_.+-]{1,}` 词，小写去重 = **152,929 词**的"已公开词汇表"。
2. **治理面抽取**：对 `docs/`+`evidence/`（fork 独有，200 文件）按 8 个**形状族**取值（ipv4 / `host=` 值 / 大写字母+数字形 / 绝对路径形 / 十六进制后缀名 / `mc|culler|shz` 资源名 / `user@host` / ssh 目标），得 1,333 条命中。
3. **求差集 + 两级归属判定**：凡在公开语料中出现过的 token 一律排除（=非我方环境事实）；剩余候选再按**出现位置**二分——出现在宿主产出的原始件（`*raw*`/`*.log`/`*.out`/`*.tsv`）者=**宿主派生**；仅出现在我方撰写文本者=**撰写面**；宿主派生者再问一层：**该值是否也出现在产品源码**（`mc/`/`runner/`/`resident/`/`dashboard/src`/`release/`）——出现=产品自带常量（非环境事实），不出现=**真环境标识**。

## 2. 结果（计数与形状，无值）
| 层级 | 数量 |
|---|---|
| 差集后候选（公开语料全无） | **218** 个去重值 |
| 其中宿主派生（见原始件） | **29** |

14 个真环境标识的类别与扩散度：`hostname-keyvalue` 1 + `machine-name` 2 = **宿主主机名族，各出现于 17 个原始件**（=扩散最广，与勘误的定性一致）；其余 11 为绝对路径形，各仅 1 个原始件。
**其中至少 3 条经阅读上下文证实是我方自造的探针夹具路径**（如容器内 `/home/probe/.codex/config.toml`、`/home/agent/.claude/*`——记录器写死的合成靶，不描述任何真实环境）。⇒ **M-2 的假阳性率不低**：14 条里约 1/5 到 1/3 属此类，需"合成夹具允许表"才能作判定用。

## 3. 对 V-1/V-2 的证据性回答（不代裁）
1. **M-2 能发现记忆漏掉的东西**：它把"宿主主机名"顶到扩散度第一（17 文件），而这恰是 v1 完全没列的一族；同时它还产出一个 v1 未见的类别（宿主绝对路径 11 条）。⇒ §3b 的 M-2 路线**可行性=已证**。
2. **M-2 不能单独作判定**：假阳性来源明确（合成夹具、工单 ID、构件名、我方自造资源名），且形状族抽取本身有覆盖上界——**本轮零命中的 `user-at-host` 族 49 个值全部落在"撰写面独有"桶**（多为文档保留域），说明形状族会同时漏（真实人名/邮箱若非 `user@host` 形则不抽）又会多。⇒ **M-1（所有者应屏蔽清单）仍是权威源，M-2 的价值是给它供候选**，M-3（形状+位置锚定）负责可执行的长期闸。三者组合关系由此从猜测变为有数据。
3. **一项正面安全事实**（此前只是推测）：**第三方租户标识在本仓零出现**——`nexusflow`/其容器名族在 `docs/`+`evidence/` 命中 **0 文件/0 次**。根因是可复核的取证纪律：全部记录器的容器枚举一律 `docker ps -a --format '{{.Names}}' | grep <自有前缀>` 并**只记录计数**（`a14-v1a-discovery.sh:26/28`、`a16-resource-acceptance.sh:45`、`a24-vision-acceptance.sh:38`、`a04-release-acceptance-s2.sh:201`），从不落全量清单。**该纪律值得从惯例升格为要件**（附五类）——否则一次"顺手 dump 一下 docker ps"就会把共用宿主上的他人服务名永久写进证据件。
4. 本件的候选值表在仓外且**在本机重启后不保证存续**（`~` 下不受 `/private/tmp` 清理影响，但未纳入任何备份面）：若所有者要长期用 M-1，须由所有者自持副本——执行侧不代管权威清单（与"风险接受不可代签"同理）。
