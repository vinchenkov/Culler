Experiment glossary


Genetic-Pareto (GEPA)
The library that controls directive evolution.


Pilot
A Culler step that checks cases, the rubric, and trial variation before directive evolution.


Evaluator
The code that executes trials, invokes the Judge, and computes scores.


Judge
The model that assesses packet quality and supplies feedback.


Optimizer
The model that proposes directive edits from permitted training evidence.


Case
Fixed role inputs and authoritative reference facts for one change.


Trial
One directive executes on one case in a fresh role session.


Training set (trainset)
Cases that supply feedback and matched parent-child comparisons.


Minibatch
A subset of training cases for one proposal task.


Validation set (valset)
Fixed cases that supply scores for parent selection and the returned candidate.


Final holdout set
Independent cases that compare the selected candidate against the original after search ends.


Proposal task
A parent, minibatch, and directive component within one GEPA iteration.


Candidate pool
The original and accepted directives with stored validation scores.


Parent selection probability
The native probability of a candidate supplying the next directive edit.


Contract failure
A packet or terminal result violates a required rule.


Critical failure
A material factual error or omission invalidates the packet's representative explanation.


Qualification
The final comparison and human review support source adoption. Source adoption remains separate.
