    01 · Fixed cases

    Three sets, three purposes

    Training set

    Validation set

    Its scores guide parent selection and the returned candidate.

    Final holdout set

    It compares the returned directive with the original. The Optimizer cannot access it.

    The default corpus covers seven change types in every set. Repeated trials remain distinct from independent cases.

    Include or exclude cases

    Each case stays in its assigned set. This preserves the final holdout. GEPA names the training set trainset and validation set valset.
