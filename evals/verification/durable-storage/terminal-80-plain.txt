usage: culler-evals serve [OPTIONS]
       --protocol FILE

Configure Genetic-Pareto (GEPA) experiments in the browser. Each experiment
starts only when you select Start experiment.

options:
  -h, --help          show this help message and exit
  --protocol FILE     Use these experiment defaults.
  --preset NAME       Select a saved preset before the browser opens.
  --source DIR        Use this Culler source checkout.
  --output-root DIR   Save experiments in persistent storage. Default:
                      ~/.local/share/culler-evals/experiments.
  --cache DIR         Use this cache for pinned case repositories. Default:
                      ~/.local/share/culler-evals/cache.
  --credentials FILE  Use this private credential configuration.
  --port PORT         Use this loopback port. The default selects an available
                      port.
  --no-browser        Print the browser address without opening a browser.

COMMAND: run help
EXIT: 0
usage: culler-evals run [OPTIONS]
       --protocol FILE --output DIR
       --cache DIR

Run Genetic-Pareto (GEPA), compare its candidate on the final holdout set, and
show live records. Source adoption remains separate.

options:
  -h, --help          show this help message and exit
  --protocol FILE     Use this complete experiment configuration.
  --source DIR        Use this Culler source checkout.
  --output DIR        Save the run in a persistent directory outside temporary
                      storage.
  --cache DIR         Use this cache for pinned case repositories.
  --credentials FILE  Use this private credential configuration.
  --resume            Continue the unchanged run in the output directory.
  --port PORT         Use this loopback port. The default selects an available
                      port.
  --no-browser        Print the viewer address without opening a browser.
  --no-wait           Close the live server after the run. Preserve the portable
                      viewer.

Restore an absent experiment directory from its local backup. Recovery preserves
existing records and makes no model calls.

positional arguments:
  backup      Use this experiment backup. Existing records remain unchanged.

  -h, --help  show this help message and exit
