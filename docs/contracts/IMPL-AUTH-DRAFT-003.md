- 状态链（唯一合法序）：`CODED → EVIDENCED（含明确 UNVERIFIED+脚本五要件齐备）→ 真机验收（所有者执行）→ 缺口关闭`；**F0a Exit 不因开发证据齐备而自动通过**。
