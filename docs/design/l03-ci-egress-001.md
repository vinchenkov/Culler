## 3. 方案骨架（外溢闸=脚本节点三件套的实例，与 L01 同形；L01 未实施不构成依赖——本票自带判定语义）
| 要素 | 内容 |
|---|---|
| 扫描器 | 仓库内检查件（Python 零依赖，对齐 release/*.py 家族惯例）：对目标字节集跑**内部标识模式库**——RFC1918/ULA 段+我们登记过的操作性地址、内部主机名/SSH 配置名、演练账户名/uid 钉、云密钥形（AKID/LTAI/… 通用超集，含 GitHub secret scanning 不认的阿里/腾讯形）、人名哈希形、私网 DNS 名；**嵌套容器**：tar/tgz/zip 成员同样入扫描（A16/A04 原始件即此形） |
| 模式库 custody | **库本身不得明文入库**（列明内部主机名的清单外泄=检查器自漏）。落法候选：(a) 模式经 SHA-256/加密摘要存储+本地对照物哈希匹配；(b) 操作员侧未跟踪文件（本地 MC_HOME 类路径）+仓内只存形状规则（正则族：私网段/密钥前缀/哈希形）。执行侧倾向 **b 形状规则入库+具体值留宿主外**，决定归所有者（V-1） |
| 判定 | 退出码+`ACCEPT: PASS/FAIL` marker 双条件（L01 同律；R1 假阳性教训：marker 判定谓词本身要有负证） |
| 产物 | 原始块（ts/host/扫描对象数/命中行号零值输出=只报"文件:行:模式 ID"，不回报命中**值**——命中值再泄一次=反模式） |
| 红绿样例 | 植入必红/清除必绿的样例夹具入 fast suite（AGENTS"测试证真实行为"）；样例的"内部值"用合成假值（0xFF 段/示例账户名），真值样例永不入库 |

## 3b. 方法学前置（由 G-4 普查的实证教训推出，非新增功能）
`evidence/L03/g4-census-001.md` 的勘误（`g4-census-erratum-001.md`）证明了一件事：**族表不可由记忆枚举**。普查按"我记得点过哪些标识"列族，结果漏掉频率最高的宿主主机名族（工作树 202 处/22 文件，历史 252 次）——因它是 `uname -n` 被动取得、我从未点过名。故扫描器的**模式库来源**必须是下列之一，而非作者记忆：
- (M-1) **所有者应屏蔽清单**（权威、可审、需维护）；
- (M-2) **先定公开面，再对"公开前后差集"做无假设 token 抽取**（机器发现未知族，代价=噪声与人审）；
- (M-3) **形状规则 + 位置锚定**（本轮已证其对"被动取得的环境值"覆盖率不足）。
**执行注意**：任何以"清单已列 X 族"为形式的覆盖率声明，须同时声明其枚举方法（M-1/2/3），否则不得作 coverage 声明（negative-list≠coverage-proof）。
